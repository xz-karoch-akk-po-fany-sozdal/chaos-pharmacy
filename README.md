# Chaos Pharmacy / Аптека Хаоса 1.1.0 (Fabric 1.20.1)

Объединённый мод: аптека (Claude) + Chaos Expansion (идеи ChatGPT) + мост к Upgrader (идея Gemini).
С Disabilities работает через его команды `/disability give|remove|next|list`. Без Disabilities и Upgrader всё тоже запускается.

## Как собрать jar
1. Поставь JDK 17 (например Temurin 17) и Gradle 8.5+ (или IntelliJ IDEA).
2. В папке проекта: `gradle build`
3. Готовый мод: `build/libs/chaos-pharmacy-1.1.0.jar` (файл `-sources.jar` не нужен).
4. Положи его в `.minecraft/mods` вместе с Fabric Loader, Fabric API и Disabilities.

Без установки: залей папку в GitHub-репозиторий, вкладка Actions -> build -> скачай артефакт.

## Предметы
Аптека: Таблетка «Само пройдёт», Таблетка «Ой», Панацея, Песочные часы Судьбы, Билет «Авось», Подозрительный банан, Утка-Диагност, Автомат Хаоса (ПКМ с изумрудом).
Chaos Expansion: Осколок хаоса, Глитч-печенье (перемешивает хотбар), Проклятые кости, Резиновая курица, Подозрительное яблоко, события хаоса раз в 8 минут.
Мост: Нестабильный предохранитель - ПКМ по блоку с "upgrad" в id (мод Upgrader) или по кузнечному столу даёт случайный хаос-эффект.
